# Product Steering

## Project Context

This project is a university research prototype for a gamified IT security awareness learning application.

The main focus is not only the game itself, but also the evaluation of an AI-assisted vibe coding approach using Kiro.

## Product Goal

The application should provide an interactive browser-based learning experience that helps users recognize common IT security risks in everyday work situations.

## Target Audience

The target audience consists of employees without a technical background who participate in IT security awareness training.

## MVP Scope

The MVP should include:

- A playable browser-based prototype
- One initial level about phishing awareness
- Scenario-based decision making
- Immediate feedback after each decision
- Score calculation
- Local progress persistence
- No login
- No backend

## Out of Scope

The following features are intentionally excluded from the MVP:

- User accounts
- Central database
- Admin area
- Multiplayer features
- Real tracking of employee behavior
- Production-ready security training platform
