# Technisches Steering

## Tech Stack

Die Anwendung soll folgende Technologien verwenden:

- React
- TypeScript
- Vite
- localStorage für lokale Fortschrittsspeicherung
- GitHub Pages für statisches Hosting

## Architekturprinzipien

- Die Anwendung bleibt rein frontend-basiert.
- Backend-Komplexität vermeiden.
- Spieldaten lokal und editierbar halten.
- Spieldaten, Spiellogik und UI-Komponenten voneinander trennen.
- Einfachen und verständlichen Code gegenüber technischer Raffinesse bevorzugen.

## Persistenz

Der Spielfortschritt wird lokal im Browser über localStorage gespeichert.

Die Anwendung erhebt keine personenbezogenen Daten.

## Hosting

Der fertige Prototyp soll als statische Webseite über GitHub Pages deploybar sein.

## Entwicklungseinschränkungen

Das Projekt wird mit einem begrenzten AI-Token-Budget entwickelt.

Daher gilt:

- Mit einem kleinen MVP starten.
- Unnötige Abhängigkeiten vermeiden.
- Ein Feature nach dem anderen implementieren.
- Aufgaben klein und überprüfbar halten.
